# Personal Expense Tracker

A personal expense tracker built with Python.

## Features

- Add expense records
- View all expenses
- Calculate total expenses
- View category statistics
- Search expense records
- Update expense records
- Delete expense records

## Technologies

- Python
- Git
- GitHub

## How to Run

1. Clone this repository.
2. Open the project folder.
3. Run the following command:

```bash
python main.py
```

## Note

Expense records are currently stored in memory.
Data will be reset when the program exits.
